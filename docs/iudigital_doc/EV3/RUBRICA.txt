Objetivo
Aplicar los conceptos de persistencia de datos, base de datos NoSQL (Firestore), operaciones CRUD y comunicación asíncrona para integrar CreditSmart con Firebase, permitiendo que los datos se almacenen en la nube, se consulten en tiempo real y persistan entre sesiones, completando así el ciclo completo de una aplicación web moderna.
